# Lanforge

> A personal forge for AI workflows, Agent Skills, prompts, and engineering notes.

Lanforge 是一个持续积累的个人 AI 工程实践仓库，用来整理和沉淀我在 **AI Agent、Skills、Prompt Engineering、AI Coding、知识管理与开发工具** 等方向上的实践。

## 📌 项目定位

Lanforge 不是一个单一产品或框架，更像是一个个人 AI 工作台：把日常使用中真正有效的 **Prompt、可复用的 Skill、工具研究笔记和 Agent 工程规范** 整理成结构化资产，方便快速查找、复用和持续迭代。

仓库中的内容会从实际使用出发，经过验证后再逐步整理、抽象和完善。每个一级目录都有自己的 README，负责说明该类内容的定位、索引和使用方式。

## 🌱 About

Lanforge 不是一个追求收集数量的 Prompt / Skill 大全。

这里更关注：

> **真正用过、确实有效、值得留下，并且以后还能继续复用的东西。**

很多内容最初可能只是一个简单 Prompt、一条工程经验或者一次工具尝试；如果它在实际使用中不断被验证，就会逐渐被整理、抽象和完善。因此这个仓库本身也会持续演化。

部分内容来自对公开项目、文章和社区实践的学习、翻译或二次整理，具体来源与上下文以对应文件中的说明为准。
