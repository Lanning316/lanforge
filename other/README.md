## 📝 内容索引

### [`个人AGENTS.md`](./个人AGENTS.md)

个人使用的 AI 工程开发原则与 Agent 编码约束。

核心原则包括：

- 以第一性原理理解真正需求
- KISS
- 不为假设中的未来需求提前设计
- 优先最小可工作实现
- 不随意增加依赖
- 不顺手重构无关代码
- 优先长期可维护方案
- 修改后尽可能进行验证

可以作为项目级或全局 `AGENTS.md` / `CLAUDE.md` 的参考。

## 🚀 使用方式
