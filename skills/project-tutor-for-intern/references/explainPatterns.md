# 通俗类比库

在技术概念首次出现且用户可能不熟悉时使用。先给准确的一句话定义，再使用类比，最后指出类比的边界。不要为了活泼而牺牲准确性。

## 使用格式

```markdown
**术语**（准确的一句话解释）。你可以暂时把它理解为“{类比}”；不过这个类比不包含 {重要边界}。
```

## Web 与前端

| 术语 | 大白话 | 可用类比 |
| --- | --- | --- |
| 组件 | 可独立复用的一块界面和行为 | 积木块 |
| 路由 | 根据地址选择页面或处理逻辑 | 导航地图 |
| 状态管理 | 在多个界面之间保存和同步状态 | 共享记事本 |
| 属性参数 | 上层传给下层组件的输入 | 填好的订单 |
| 客户端渲染 | 浏览器拿到数据后组装页面 | 顾客在桌边自己组合套餐 |
| 服务端渲染 | 服务器先生成页面再交给浏览器 | 厨房做好整份餐点再端上来 |

## 后端与系统

| 术语 | 大白话 | 可用类比 |
| --- | --- | --- |
| API | 系统对外提供的调用约定 | 服务窗口 |
| 中间件 | 在核心处理前后统一执行的逻辑 | 安检通道 |
| 数据库 | 持久保存和查询结构化数据的系统 | 有目录的仓库 |
| ORM | 在程序对象与数据库记录之间转换 | 双语翻译 |
| 缓存 | 保存高频结果以减少重复计算或访问 | 手边的便签 |
| 消息队列 | 解耦发送者与处理者的异步通道 | 取号排队 |
| 网关 | 统一接收、检查并分发外部请求 | 大楼前台 |
| 鉴权 | 判断调用者身份和允许的操作 | 查验门禁卡 |
| 事务 | 让一组数据操作共同成功或共同失败 | 一张不可拆分的转账单 |
| 分布式锁 | 协调多个进程对共享资源的访问 | 共享房间的门锁 |
| 幂等 | 同一操作重复执行仍保持同一结果 | 重复按电梯按钮 |
| 限流 | 控制单位时间内接受的请求数量 | 场馆限流 |
| 熔断 | 下游持续失败时暂时停止调用 | 自动断开的保险丝 |

## 架构与设计

| 术语 | 大白话 | 可用类比 |
| --- | --- | --- |
| 分层架构 | 按职责把处理过程拆成依赖方向明确的层 | 流水线 |
| 依赖注入 | 从外部提供对象所需的依赖 | 配送到岗的工具箱 |
| 接口 | 约定对象必须提供哪些能力 | 插座规格 |
| 工厂 | 根据输入集中创建不同对象 | 定制生产线 |
| 单例 | 在限定范围内共享同一个实例 | 一个总控台 |
| 观察者 | 状态变化时通知订阅者 | 消息订阅 |
| 策略 | 在相同目标下替换不同算法或行为 | 导航路线选择 |
| 插件 | 遵循扩展契约、可独立装配的功能 | 可更换模块 |
| 事件驱动 | 组件通过事件触发后续处理 | 广播通知 |

## 通用编程

| 术语 | 大白话 | 可用类比 |
| --- | --- | --- |
| 变量 | 保存一个可引用值的名称 | 贴标签的盒子 |
| 函数 | 接收输入并执行一段可复用逻辑 | 加工机器 |
| 回调 | 事情完成后调用预先提供的函数 | 办完后回电话 |
| 异步 | 发起任务后不必原地阻塞等待 | 取号后先做别的事 |
| 递归 | 函数在更小问题上调用自己 | 逐层打开套盒 |
| 并发 | 多项任务在时间上交错推进 | 一个厨师轮流照看多口锅 |
| 并行 | 多项任务在同一时刻真正执行 | 多个厨师同时做菜 |

## 类比边界

- 类比不能替代定义。
- 不同项目对同一术语可能有不同职责，以当前代码为准。
- 一个类比解释不了错误处理、性能或生命周期时，要直接指出。
- 用户已经熟悉术语时，省略类比，直接讲项目特有决策。
