### [`ponytail.md`](./ponytail.md)

一种面向 AI Coding Agent 的“反过度设计”思路。

核心理念不是单纯追求代码最短，而是：

> **在保证正确、安全和可维护的前提下，尽可能少写代码。**

强调优先复用现有代码、减少抽象层、避免不必要的依赖和脚手架。
